# Battle Spirits Card Images

Place card image files in this directory with the following naming convention:

## Spirits
- `spirit_recruit.jpg`
- `spirit_soldier.jpg`
- `spirit_knight.jpg`
- `spirit_warrior.jpg`
- `spirit_mage.jpg`
- `spirit_moon_shacco.jpg`
- `spirit_genie_bow.jpg`
- `spirit_ro_meek.jpg`
- `spirit_haria.jpg`
- `spirit_gun_gata.jpg`
- `spirit_graipher.jpg`
- `spirit_seldalius.jpg`
- `spirit_lev_falus.jpg`
- `spirit_cubel.jpg`

## Nexuses
- `nexus_shrine.jpg`
- `nexus_stone.jpg`
- `nexus_wind_fang_rock.jpg`

## Magic
- `magic_slash.jpg`
- `magic_heal.jpg`
- `magic_draw.jpg`

## Image Format
- Format: JPG or PNG
- Recommended size: 300x420px (standard card size)
- Color mode: RGB or RGBA

## Usage
The system will automatically reference images from these paths. Web UI and other frontends will display the card images alongside game state.
